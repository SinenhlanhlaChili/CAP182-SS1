
# SS3 Dataset

This directory contains the datasets used for the CAP182 SS3 project on predicting 30-day hospital readmission.

## Dataset files

- `table1_admissions_adt.csv` – Admission, discharge and transfer data.
- `table2_patient_clinical.csv` – Patient clinical and demographic data.
- `table3_previous_utilisation.csv` – Previous healthcare utilisation data.
- `table4_discharge_readmission_outcome.csv` – Discharge and readmission outcome data.

## Data description

The four tables are linked using patient and admission identifiers to create the analytical dataset.

**Data governance:** The supplied dataset is synthetic and is used for academic purposes only.
